## How it works

`main.py` (Python standard library only) writes a single word — Indonesian slang
for profit, money in the pocket — to `/output/entry.txt` with no trailing
newline. Before writing it asserts the bounty gate: the word is 1–30
characters, non-whitespace, exactly one word with no spaces. After writing it
reads the file back and re-checks that the content on disk is exactly the word,
with no trailing whitespace.

Run it with:

```sh
python3 main.py
```
